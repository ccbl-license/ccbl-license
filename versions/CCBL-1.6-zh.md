- 人工智能模型被训练于本软件（全部或部分）；**并且**

“被训练于本软件”包括直接和间接接触，无论本软件是通过 GitHub 公开仓库、第三方数据集、API 调用或其他任何途径被纳入训练数据。

无论输出代码在语法上与原软件有多大差异，变量名、函数名是否被重命名或混淆，均不影响上述认定。
