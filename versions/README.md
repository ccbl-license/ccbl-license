# CCBL Version History

This directory contains the complete, unaltered text of each released version of the Contribution-Commercial-Benevolent License (CCBL).

## Available Versions

| Version | Release Date | TXT (Authoritative) | MD (Readable) | Summary of Changes |
| :--- | :--- | :--- | :--- | :--- |
| **1.7** | 2026-06 | [TXT](./CCBL-1.7.txt) | [MD](./CCBL-1.7.md) | Qualified Contributor now limited to natural persons (personal & non-transferable); valid contribution requires explicit maintainer acceptance (no 60-day silent approval); added sublicensing & patent grant in contribution terms; binary distribution now allowed with source availability; added termination cure period (60 days); added Section 11 patent grant & retaliation; tightened SaaS clause; clarified dispute resolution via written notice; later versions may not diminish granted rights |
| **1.6** | 2026-01 | [TXT](./CCBL-1.6.txt) | [MD](./CCBL-1.6.md) | Initial public release. Core features: contribution-for-free-use, AI policy, 1% donation pledge, trademark protection, anti-SaaS clause |

## Which File Should I Use?

| Purpose | Recommended File |
| :--- | :--- |
| **Start a new project** | Copy `LICENSE` from repository root (or `CCBL-1.7.txt`) |
| **Legal review / citation** | `.txt` version (exact legal text) |
| **Quick reading in browser** | `.md` version (better formatting) |

## Policy for Versions

- **Current version**: CCBL 1.7 (in root `LICENSE` file)
- **Future versions**: When a new version (e.g., 1.7, 2.0) is released, the previous version will be archived here with both `.txt` and `.md` formats.
- **Using older versions**: Projects may continue to use any past version of CCBL. There is no requirement to upgrade.
