# CCBL — Contribution-Commercial-Benevolent License

[![License Version](https://img.shields.io/badge/version-1.6-blue.svg)](./LICENSE)
[![Official Website](https://img.shields.io/badge/website-ccbl.cc-brightgreen.svg)](https://ccbl.cc)

This repository is the **authoritative source** for the CCBL (Contribution-Commercial-Benevolent License) text and its supplementary policies.

## Repository Purpose

- **`/LICENSE`** : The canonical English text of the CCBL 1.6.
- **`/AI_POLICY.md`** : The official AI Supplementary Policy, incorporated by reference into the license.
- **`/versions/`** : Historical versions of the license (1.0 – 1.5).
- **`/docs/`** : Source files for the official website ([ccbl.cc](https://ccbl.cc)).

## Official Website

For a human-friendly explanation, FAQs, comparison with other licenses (MIT, GPL, BSL), and the **Chinese version** of the license, please visit: **[https://ccbl.cc](https://ccbl.cc)**

## Using CCBL in Your Project

1. Copy the plain text from the [`/LICENSE`](./LICENSE) file.
2. Place it in your project's root directory as `LICENSE`.
3. Replace the placeholders: `[year]` and `[copyright holder name]`.
4. (Optional) Add the [`/AI_POLICY.md`](./AI_POLICY.md) file to your project root to clarify your stance on AI use.
